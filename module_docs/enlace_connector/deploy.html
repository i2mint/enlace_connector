enlace_connector.deploy

Generate everything needed to deploy a connector on an enlace platform.

In production, enlace only reverse-proxies a mode="process" app’s route to 127.0.0.1:{port} — the connector’s actual process runs under a systemd unit in its own venv (enlace delegates production process management to systemd). So a full deploy is more than an app.toml; this module renders the whole bundle from a ConnectorSpec:

  • the systemd unit (runs the connector in its dedicated venv),

  • the provisioning script (build that venv + install deps + create data dirs + install/start the unit — idempotent, run as root on the box),

  • the resource-allowlist TOML fragment for platform.toml (access control),

  • a runbook listing the human steps (ship data, provision, deploy, connect).

It generalizes the artifacts first hand-written for the trufflepig connector, so deploying the next one is generate_deploy_bundle(spec) + following the runbook. Platform specifics (paths, origin) are parameters with tw_platform defaults — enlace_connector stays connector-type-agnostic (it knows nothing of ir).

enlace_connector.deploy.DFLT_REMOTE_BASE = '/opt/tw_platform'

Defaults for the tw_platform target (override per call for another platform).

enlace_connector.deploy.MCP_PATH = '/mcp'

FastMCP’s Streamable-HTTP sub-path — the OAuth resource is route + MCP_PATH.

enlace_connector.deploy.generate_deploy_bundle(spec: ConnectorSpec, dest: str | Path, *, remote_base: str = '/opt/tw_platform', issuer: str = 'https://apps.thorwhalen.com', server_py: str | None = None) → dict[str, Path][source]

Write the full deploy bundle for spec under dest.

Writes the app dir (app.toml + server.py) and a deploy/ folder (the systemd unit, provisioning script, allowlist fragment, runbook). Pass server_py to override the generated entry module (e.g. a corpus-bound make_search server the composing skill wrote). Returns the written paths.

enlace_connector.deploy.render_allowlist_toml(spec: ConnectorSpec, *, issuer: str = 'https://apps.thorwhalen.com') → str[source]

Render the [auth.oauth_server.resource_allowlist] fragment (or "").

Empty when allowed_users is empty (connector open to any authenticated user). Otherwise maps this connector’s resource URL to the allowed emails — paste into the platform’s platform.toml.

enlace_connector.deploy.render_provision_script(spec: ConnectorSpec, *, remote_base: str = '/opt/tw_platform') → str[source]

Render the idempotent, run-as-root provisioning script for the connector.

Builds the dedicated venv (this box’s ensurepip is unavailable, so --without-pip + get-pip.py, using the same base interpreter that made the shared venv), installs extras + git_installs, creates the data dirs, runs post_install (e.g. warm a model), and installs/starts the unit.
